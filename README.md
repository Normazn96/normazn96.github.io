# Nan Zhao — academic homepage

This repository publishes Nan Zhao's academic homepage at
`https://normazn96.github.io/`.

The public site is intentionally concise. It includes basic academic information,
education, research and clinical interests, peer-reviewed publications, and selected
professional links. It does not publish a CV, phone number, street address, GPA,
supervisor details, or unpublished work.

## Updating the website

Public website files are kept in `site/`. Updates pushed to `main` are checked and
published automatically by the GitHub Pages workflow.

The contact address is written with the words `AT` and `DOT` instead of symbols. This
keeps it readable without requiring a mail application and discourages basic address
harvesting, although no public display method can guarantee complete protection from
determined scraping.
